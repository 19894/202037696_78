## Descripción
Este repositorio contiene los programas desarrollados en Python para la actividad final de Lenguajes Interpretados, correspondientes a la recuperación y organización de códigos de las tareas anteriores.

## Archivos del proyecto

### 1. Tarea 2 – Sensor INA219
Archivo: tarea2_ina219.py.txt

Programa de simulación para monitorear el voltaje de un banco de baterías y aplicar condiciones de protección.

### 2. Tarea 3 – Sensor Eastron SDM630
Archivo: tarea3_sdm630.py.txt

Programa que organiza y visualiza los registros del sensor de energía Eastron SDM630 mediante diccionarios.

### 3. Tarea 4 – Optimización
Archivo: tarea4_optimizacion.py.txt

Programa de simulación para validar lecturas de frecuencia y medir el tiempo de ejecución.
