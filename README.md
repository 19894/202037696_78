### 1. Tarea 2 – Sensor INA219
Archivo: tarea2_ina219.py.txt

Programa desarrollado en Python para simular el monitoreo del voltaje de un banco de baterías mediante condiciones de protección.

Archivo: tarea3_sdm630.py.txt

Programa desarrollado en Python para organizar y visualizar los registros del sensor de energía Eastron SDM630 mediante diccionarios.

### 3. Tarea 4 – Optimización
Archivo: tarea4_optimización.py.txt

Programa desarrollado en Python para validar lecturas de frecuencia y medir el tiempo de ejecución.
