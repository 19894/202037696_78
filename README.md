## Descripción
Este repositorio contiene los programas desarrollados en Python para la actividad final del curso Lenguajes Interpretados, correspondientes a la recuperación, organización y ejecución de códigos de las tareas anteriores.

## Archivos del proyecto

### 1. Tarea 2 – Sensor INA219
Archivo: tarea2_ina219.py.txt

Programa desarrollado en Python para simular el monitoreo del voltaje de un banco de baterías mediante condiciones de protección. Permite identificar diferentes estados de funcionamiento según los niveles de voltaje establecidos.

### 2. Tarea 3 – Sensor Eastron SDM630
Archivo: tarea3_sdm630.py.txt

Programa desarrollado en Python para organizar y visualizar los registros del sensor de energía Eastron SDM630 mediante el uso de diccionarios. Incluye información del voltaje, corriente y frecuencia.

### 3. Tarea 4 – Optimización
Archivo: tarea4_optimizacion.py.txt

Programa de simulación desarrollado en Python para validar lecturas de frecuencia dentro de un rango establecido y medir el tiempo de ejecución del proceso.
